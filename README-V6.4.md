# ProCoach V6.4 — Smart Performance & Workflow

Evolução construída sobre a V6.3.1.

## Novidades

- Central de Atenção com alertas de dor, prontidão, PSQ pendente, atividades/vídeos vencidos e dúvidas.
- Índice individual de desenvolvimento baseado somente nos componentes com dados disponíveis: plano individual, atividades, mídia, PSQ e presença.
- Dashboard de adesão ao ProCoach Athlete.
- Sugestões de complemento, recuperação ou coleta de PSQ com confirmação humana obrigatória.
- Comparação longitudinal Atleta × ele mesmo: semana atual versus anterior.
- Timeline 360° integrada no Perfil do atleta com PSQ, PSE, atividades, vídeos, academia, metas e movimentações entre categorias.
- Cache PWA atualizado para `procoach-v64-smart-performance`.

## Observação importante

O índice de desenvolvimento é um indicador operacional de adesão/evolução do processo. Não representa talento, potencial, valor esportivo ou ranking entre atletas. As sugestões de carga nunca são enviadas automaticamente; a comissão revisa e confirma.
